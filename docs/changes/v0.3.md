# v0.3 变更记录

日期：2026-08-23–2026-08-24

## v0.3.4 TechFlow 新闻审计中心

- 首页新增“查看全部新闻判断”入口，独立 `/news` 页面显示功能启用后程序实际观察到的全部 TechFlow 独立快讯，包括未进入风险观察和需要人工复核的项目。
- 每条新闻在首次接收及每次内容 revision 时生成不可覆盖判断，依次检查宏观相关、风险方向、影响程度和 120 分钟观察窗口；页面只显示自然中文，不铺出后台枚举、来源 ID、evidence ID 或 hash。
- 新增本地 `0600` append-only 新闻审计 journal、180 天 retention、schema/hash 校验、冲突阻断和重启恢复；只保存规范化元数据、链接和最多 600 字摘要，不保存完整正文。
- 新增只读分页/筛选/搜索 API 与 revision 详情；OpenAPI 明确 query/path 参数和 400/404 响应。
- TechFlow freshness 从 180 秒收紧到 30 秒；fetch 与 body 共用 8 秒显式截止，单次悬挂不会永久阻断轮询，恢复和累计错误保持可见。
- 活跃配置版本为 `0.3.2`，使用新的 cursor、新闻审计和 Shadow journal 路径；旧 v0.3.1 Shadow 原样保留但不与新 freshness 语义混算。
- 外部输入仍严格只有 TechFlow 与 Binance Spot；没有增加 RPC、第二新闻源、付费源、LLM 热路径、钱包或交易能力。

## v0.3.2 前端决策语言修订

- 首屏改为先回答“现在要不要操作”，再显示减仓与回补各自满足数量。
- 两个数据源收敛为“新闻/行情：正常、连接中、延迟或不可用”的状态摘要，不再展示 transport、计数器、capability 和 evidence ID。
- 每项条件只显示中文状态、可视进度、“现在怎样”和“还差什么”；阈值表、持续时间、来源年龄与证据带退出默认前端，但继续保留在后台数据、日志和测试中。
- `SHADOW/CEX_REFERENCE/STAGE/OUTPUT/PASS/FAIL/UNKNOWN/STALE` 等原生枚举不再直接出现在读者界面；只读与 DEX 手工确认边界改为自然语言。
- 浏览器标题改为“VIRTUAL 风险雷达”，并增加原生字段不得回流前端的组件测试。

## v0.3.1 数据完整性修订

- 将高频行情摄入与决策/schema 评估解耦：消息快速入窗，状态机每秒批量刷新。
- 滚动窗口从数组头部逐项移动改为游标推进与分段压缩，并增加 10,000 条高频回归测试。
- 性能修复前的 journal 保留为诊断证据；当前 Shadow 使用 `data/runtime/v3-shadow-v0.3.1.jsonl` 从零重新计时，避免旧延迟样本污染 60 分钟和 14 天结论。

## 产品范围

- 活跃来源收敛为 TechFlow 免费公开快讯与 Binance Spot。
- 资产固定为 BTC、ETH、SOL、VIRTUAL。
- 默认输出固定为 `CEX_REFERENCE`；实际 DEX quote 与执行由用户完成。
- RPC、链、DEX quote、钱包、衍生品、多新闻源和第二交易所退出活动路径。

- v0.2 配置、状态机、schema 和命令改为显式 legacy 路径。
