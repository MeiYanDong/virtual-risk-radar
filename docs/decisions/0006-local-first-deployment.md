# ADR-0006：本地优先，Shadow 前重新评审部署

- 状态：SUPERSEDED BY ADR-0014
- 生效版本：0.1.0
- 确认人：用户
- 确认时间：2026-08-22
- 可逆性：REVERSIBLE

## 决策

开发、fixture、replay 和初期 Shadow 采用本地运行。架构保留云采集与本地控制台的迁移边界，但在连续 14 天 Shadow 前不配置生产 CD。

本地模式不承诺 24/7；电脑休眠、网络中断和数据缺口必须可见。

2026-08-25 用户选择并完成项目独占 SWAS 云端部署。本 ADR 继续解释开发与早期 Shadow 的历史形态；当前生产运行决策以 ADR-0014 为准，本地可回放能力继续保留。

## 验收与证据

对应 P0-008。历史阶段 CI 与 CD 分开；当前自动 CD 仍未配置，但已有经校验的人工云端发布链路。
